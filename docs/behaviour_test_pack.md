# Behaviour test pack

Questions and upload files that exercise every answer behaviour in the problem statement. Each test names
the question, what to upload (if anything), the expected outcome, and what to check in the UI.

## Setup

```powershell
cd D:\AgenticRAG; .\.venv\Scripts\Activate.ps1
python -m samples.make_test_uploads      # creates samples\test_uploads\ (already done if the folder exists)
uvicorn app.main:app --port 8000         # then open http://localhost:8000/ui
```

**Uploading.** To attach a file with a new question, use **+ Attach a document** under the question box.
When the agent asks for something, use the file picker in the *The agent needs something from you* card.

**Pacing.** With the local model there is no rate limit; allow ~30 s after starting the API while the model loads.

**Attachments are read first.** A file attached to an investigation is read (OCR only where needed) and searched
before the model's first step; those steps appear in the timeline as automatic.

**Upload files** (`samples\test_uploads\`, generated by `samples/make_test_uploads.py`; the generator checks
with Tesseract that each file triggers its behaviour):

**Ground truth** for the main question below:
- Acme's X200 is COMMERCIAL (scanned Schedule B of the contract).
- The amendment gives commercial units bought from 1 Jan 2025 a **12-month** warranty, with labour for the
  first 6 months only.
- Motor seizure is a covered failure (X200 manual §5).
- No corpus document contains the purchase date.

> **MAIN** = *Is the motor seizure of Acme Facilities' Aquaflow X200 pump (serial AQ-X200-55871) on
> 14 March 2026 covered under warranty?*

**How the outcomes are decided.** Most outcomes are decided by code:
- verification of citations and OCR confidence;
- the unknown-entity check;
- the outcome rules.

Tests marked *(judgement)* depend on the LLM noticing something, such as a serial mismatch or a conflict.
They are the ones worth running twice.
